# 🏐 Eclipse Vôlei

- Luany Bernardi
- Marcelo Azevedo

## Tema

Nosso projeto é um jogo de vôlei chamado **Eclipse Vôlei**. A ideia é desenvolver um jogo simples em Python, utilizando a biblioteca Pygame, onde o jogador possa participar de uma partida de vôlei.

## Objetivo

O objetivo do jogo é fazer com que o jogador controle um personagem durante uma partida, podendo se movimentar pela quadra e realizar diferentes movimentos para tentar marcar pontos.

Além disso, o projeto serve para colocar em prática os conteúdos aprendidos na matéria de Desenvolvimento de Sistemas, principalmente programação e lógica.

## Funcionamento

O jogo possui uma quadra de vôlei com jogadores, bola e rede. O jogador controla seu personagem pelo teclado e pode andar, pular e realizar diferentes movimentos, como manchete, toque, cortada, largadinha, mergulho e saque.

O jogo possui alguns modos diferentes, como **1 contra 1**, **2 contra 2** e **1 contra 1 local**, além do modo de treino. Nos modos contra o computador, os outros jogadores são controlados pelo próprio jogo.

Durante a partida, o placar é atualizado conforme os pontos são marcados. O jogo também possui sistema de sets e algumas regras básicas do vôlei, como o limite de toques da equipe.

O objetivo principal é fazer a bola cair na quadra adversária para marcar pontos e vencer a partida.
